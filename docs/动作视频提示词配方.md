# 艾莉丝动作视频提示词配方

用途：给桌宠新增或重做动作时，按此配方生成源视频，再走归一化管线入宠。这是 2026-11-17 两批动作（共 21 条视频动作）的生产方法存档，后续照此执行，不要另起炉灶。

## 一、形象锁定（每条提示词必带）

- 参考图：alice-canonical.png（本文件夹，唯一标准源），生成时作为角色参考图传入。
- 识别五重点，提示词里逐项写死：珊瑚红蓬松微卷长发、头顶大呆毛、侧发小翘角；白衬衫＋红领结＋棕色腰带＋棕色格纹背带裙、白袜棕鞋；大红眼睛带高光、腮红。
- 画风：扁平 2D、色块干净、线条简洁。不要 3D 感、不要厚涂、不要写实。

## 二、单条提示词结构

一段话讲清四件事：

1. 角色：引用第一节的形象锁定全文，不要简写。
2. 动作：只写一个动作，写清起始姿势、动作过程、结束姿势；循环动作要求结束姿势回到起始姿势（首尾衔接）。
3. 机位与画面：人物全身入画、位置固定在画面中央、镜头不动、人物不走出画面。
4. 背景：纯色绿幕（或纯色单色背景），无道具、无其他人物、无文字。

时长与规格：源片约 10 秒、24fps；生成工具按其上限出片即可，后处理统一。

## 三、动作清单（已入宠的 22 个）

精灵图组（主人精灵图切片，非视频生成）：待机呼吸、走路、爱心、睡觉。

视频组（按本配方生成）：
- sit：坐下安静待着，偶尔眨眼
- wave：抬手挥手打招呼
- celebrate：开心庆祝，小跳加挥手
- water：喝水，举杯到嘴边再放下
- fish：摸鱼，低头偷懒打盹一下又抬头
- wiggle：左右扭动卖萌
- clickhappy：被点后开心，眼睛弯成月牙
- clickshy：被点后害羞，双手捂脸侧头
- clicktsun：被点后傲娇，抱臂扭头哼一声
- wakeup：睡醒，揉眼伸懒腰
- yawn：打哈欠，手遮嘴，眼睛眯起
- startled：受惊，身体一抖后退半步
- dragdangle：被拖拽悬空，四肢自然下垂轻轻晃（循环）
- sleepstart：从站立慢慢困倦、坐下入睡（一次性，播完接睡觉循环）
- thinking：思考，托腮抬头望天（循环）
- pacing：等待，背手来回踱步（循环）
- tidying：整理，弯腰收拾桌面动作（循环）
- sigh：叹气，肩膀垮下摇头（一次性）

## 四、后处理管线（生成后固定走）

1. 抠像：去绿幕/纯色底，得透明帧序列。
2. 归一化：帧尺寸统一 400×462，人物脚底基线对齐。
3. 插帧：ffmpeg minterpolate 补到 60fps（注意：这是插帧 60fps，不是源生 60 帧，对外说明时要讲清）。
4. 量化：PIL 调色板量化压体积（全套曾从 628MB 压到 102MB，画质以肉眼无明显色带为准）。
5. 入宠：帧目录放 AliceButler/assets 对应组（anim60 / anim-flat），pet.cs 里接线触发条件（待机池权重、单击池、presence 状态映射），部署走 ~/workspace/tools/deploy-pet.sh。
6. 验收：部署后看 pet-start.log 与 pet-error.log，确认进程在 session 1、帧数与源一致、无报错。

## 五、红线

- 不改脸、不改配色、不丢呆毛；新动作宁可不做，不要形象走样。
- 生成图/视频不得冒充实拍。
- 源片与原始帧备份体积大，删减前先报主人确认。
