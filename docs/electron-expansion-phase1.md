# 艾莉丝桌宠 · 扩展素材一期验收

本批在 `dev/electron-pet` 上接续 `cc293cf`。源片取自 `main` 的 `5b90d8a`，共四个经选定的 MP4。运行时配置现登记 13 段视频。本次验证使用 Linux 虚拟桌面，部署和 Windows 实机验收留给 PC 侧。

## 素材

四个源片均为 1248×704、24 fps、240 帧。沿用仓内 HSV 绿幕抠像、透明边缘去溢色及预乘 alpha 插值，逐帧把人物最大连通域的脚底与中心对齐，输出 640×360、24 fps、VP9-alpha。站姿目标高度为画布的 68%。坐倒段随坐下和撑地起身在 68% 与 52% 之间过渡。下表为解码后全部 240 帧在 alpha > 32 下的测量范围。单段上限按 3,000,000 字节验收。

| 段 | 编码 | 字节 | 脚底 / 高 | 中心 / 宽 | 人物高度 / 高 |
|---|---|---:|---:|---:|---:|
| dangle | 循环，固定 Q24，首尾独立关键帧 | 1,066,141 | 85.00% | 51.02–51.09% | 67.78–68.06% |
| sitdown | 单次，CRF 28 | 750,069 | 85.00% | 51.02–51.09% | 51.94–68.06% |
| peek | 循环素材，固定 Q24，悬停触发时播放一遍 | 508,487 | 85.00% | 51.02–51.09% | 67.78–68.06% |
| startled | 单次，CRF 28 | 796,834 | 85.00% | 50.94–51.09% | 67.78–68.06% |

抽查对照站立锚图、定版 idle、四段源片及编码后画面。红发、校服蝴蝶结、裙装及呆毛可辨。拎起段举手悬脚，坐倒段坐下后撑地站起，张望段侧头，受惊段睁大眼睛后跳。坐倒与受惊原片有发梢越过画面上沿，处理时对齐同一条源片中完整的发梢，补回越界区域；两段各有 36、3 帧进入上沿修复。第二版设计单未随包提供，表情细项与实机观感仍待主人核对。

## 接缝

用 libvpx-vp9 解码完整 RGBA 帧。dangle、peek 首尾逐通道完全相同，MAE、最大通道差和变化通道数均为 0。与 idle 交接按双方端点主体中心的水平位移验收，2% 画布宽对应 12.8 px。

| 段 | 从 idle 进入 / 回 idle 的位移（px） | 从 idle 进入 / 回 idle 的 RGBA MAE |
|---|---:|---:|
| dangle | 0 / 0 | 2.748 / 2.748 |
| sitdown | 0.5 / 0 | 2.739 / 9.276 |
| peek | 0 / 0 | 2.570 / 2.570 |
| startled | 0 / 0 | 1.841 / 7.047 |

原有 idle、walk、doze 循环 MAE 均为 0。sleepstart→doze、doze→wakeup、wakeup→idle 的 MAE 分别为 0.132885、0.132885、1.316980，与第二批一致。

## 触发与打断

| 入口 | 测法与结果 |
|---|---|
| 拎起 | 在受惊和坐倒播放中分别按住拖动，越过原有起拖距离后，两次均切到 dangle。循环随拖速倾斜，最大 7°。 |
| 坐倒 | 模拟从 15 px 高处轻放，保留挤压。分别从 100 px 高处释放、在 5 px 处以 610 px/s 下落，均走坐倒且挤压系数为 1。桌宠窗口内实际拖高松手也点播了 sitdown。 |
| 张望 | 连续命中 799 ms 未触发，800 ms 触发。保持命中只触发一次。移出后回 idle，冷却内重入无第二次播放，10 s 冷却结束后可再次触发。张望中点击切至点击反应。 |
| 受惊 | 从命中区外迅速移近再点击，窗口中连续前三次进入 startled，第四次进入 clicks 池。用滚动窗口边界测试确认最早一次满 60 s 后释放名额。 |
| 视线追逐 | 未按键时在命中区左右横划，出现 peek，镜像随方向切换。检查物理状态持续为 idle。 |
| 回来挥手 | 向 Electron 注入锁屏和解锁事件，模拟离开超过 600 s，观察 wave 首帧。重复解锁未增加播放序号。最小化与锁屏重叠、短时离开在单测中覆盖。 |
| 双击 | 经双击判定入口触发一次 wave，播放结束回 idle。采用只挥手，避免物理小跳叠加。 |

新单次段自然结束回 idle，旧播放结束事件通过播放序号丢弃。相关回归用例位于 `AliceButler/electron/tests/gestures.test.cjs`。

## 性能与测试

Linux、Electron 45.3.3、相同虚拟桌面、硬件加速默认开启。空闲五次等间隔采样中位数，四进程私有驻留内存从 162.39 升至 162.82 MiB，工作集从 469.24 降至 466.45 MiB。Windows 私有字节及 15 段完整功能的 220 MB 目标需要部署后实测。

每段交错点播三次，从渲染进程收到播放请求到确认首帧的范围为 dangle 17.6–44.8 ms、sitdown 18.1–21.8 ms、peek 17.2–20.2 ms、startled 18.6–19.7 ms。该口径不含手势判定时间与显示器呈现延迟。每项由主人在实机操作三次、检查误触漏触及感知延迟 ≤150 ms 的验收待做。

开发阶段最小测试覆盖新增的 5 条交互单测、四段素材点播、Electron 手势入口与组合打断。收尾全量涵盖 13 段点播、Electron 单测及集成、Python 素材管线单测、播放稳定性与解码接缝测量。

本次收尾全量只跑一次。16 项 Electron 单测、5 项 Python 单测和 13 段集成点播全部通过。睡眠实等 122 秒并恢复后，播放检查共采样 9,067 帧，空帧和黑帧均为 0，同时附着的视频源最多为 2 个。
