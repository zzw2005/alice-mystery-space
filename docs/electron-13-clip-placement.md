## 复查记录

clickhappy 的脚底最低坐标为 73.89%，与基准相差 11.11 个百分点，头顶到 7.22%。walk 的右缘最大到 71.72%，较 R68 向右 3.72 个百分点。clicktsun 的左缘最大到 41.25%，较 L34 向右 7.25 个百分点。doze 高度范围为 51.39–53.06%，相对 52% 的最大偏差为 1.06 个百分点。

四段扩展动作的脚底逐帧均为 85.00%。sitdown 高度为 51.94–68.06%，超出过渡区间最多 0.06 个百分点。其余三段扩展动作高度相对站姿基准最多偏差 0.22 个百分点。

本表用于复核动作摆幅和站位。重做素材或调整归一化由艾莉丝决定。复查过程中 WebM 与源视频均无改动。

复算时，在 Electron 项目目录执行 `npm run precheck -- --audit measurements.json`。输出包含每段帧数、首尾帧和整段范围。
